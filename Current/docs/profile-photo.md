# Profile photo

Tap the top-left logo on Home to switch visibly to the Settings tab, then push Profile. Back leads to Settings. The transition respects Reduce Motion. Choose Change Profile Photo from that page. The person can choose an image from the system photo picker, take a camera photo when a camera is available, or import an image file. The editor supports drag, pinch, a 100–500% zoom slider, zoom buttons, 90-degree clockwise rotation, and crop reset. The bright area inside the original SF Symbol `seal.fill` is the visible area; the saved Home avatar uses the same mask and the `seal` outline. VoiceOver exposes photo movement actions and the zoom slider as alternatives to gestures.

The Home avatar is 54.4pt inside a circular 60.8pt button, a 20 percent reduction from the prior design. On iOS 26 and later the toolbar's shared background is hidden for this item so it cannot add a capsule around the circle. Settings replaces the app-name header with the person's profile photo, name and “Member since YYYY.” Both that header and Preferences → Profile open the Profile page, which contains photo and name editing. Names set in Profile are stored with the user's ledger and included in backups. If no local name exists, the authenticated account's display name is used; an account with no supplied name shows “Your profile” until the person adds one.

Settings and Profile use a fixed 92pt photo, matching the user's selected reference size. The frame-size slider and Reset size control have been removed. The image can extend into the card's padding while its layout slot stays fixed. Its viewport protects the name area, and the entire header clips to the rounded card bounds. Historical profileFrameSize values remain decodable in ledgers/backups but no longer control the interface. Photo crop and zoom controls remain available in the upload editor.

Cash cards do not display the profile photo. Their engraved title and live cash balance are centered inside the supplied note border.

Membership uses Firebase's account `createdAt` timestamp in milliseconds, never the current login or install date. The authenticated lookup verifies the returned UID and caches the display name and creation date with the existing Keychain session. Old saved sessions remain compatible. A missing creation date is fetched when Settings opens; cached metadata survives a failed profile lookup. If no verified creation date is available, the UI shows an unavailable state instead of inventing a year. No Firebase profile write is added. Reference: [Firebase user-data fields](https://firebase.google.com/docs/reference/rest/auth#section-get-account-info).

Only Save changes the ledger. Cancel discards the editing session. Adjust Photo reopens the stored source with its saved normalized crop. Remove Photo restores the original logo.

Photo decoding uses ImageIO to normalize orientation and downsample to a maximum dimension of 2048 pixels. The original used for editing is saved as a JPEG; the rendered square avatar is 512×512. The logo mask is applied at display time. The import size limit is 20 MB, consistent with other app attachments.

Photo records and files live in the current user's existing local ledger and protected attachment directory. No new remote storage or photo-sharing endpoint is added. Complete backups include both the source and rendered avatar and rename both references on restore. Bank-only deletion preserves the photo; complete local-data deletion removes it with the rest of that ledger. Superseded attachment files follow the app's existing local recovery-file policy rather than being deleted while recovery snapshots might still refer to them.

Validation uses original synthetic images, not a user's photo library. Core checks cover aspect-fill crop geometry, zoom/edge constraints, filenames, old ledger compatibility, complete backup inclusion and attachment renaming. Simulator checks cover crop/zoom, rotate, save, relaunch/re-edit, cancel, remove and the Home logo. A physical-device check is still needed for camera capture, photo-library permissions and pinch/drag feel.
